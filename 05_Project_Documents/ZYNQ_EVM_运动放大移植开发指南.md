# ZYNQ-7000 平台 Eulerian Video Magnification (EVM) 运动放大与多模式热力图移植开发指南

---

## 一、 项目定位与任务概述

* **设计目标**：将 SIGGRAPH 2012 经典论文中的 **欧拉视频放大（EVM）** 算法移植部署至 Xilinx ZYNQ-7000 SoC FPGA 平台，并融合 **“空间降采样预处理 + 多尺度金字塔 + 微动能量场平滑 + Jet/Viridis 伪彩热力图半透明叠加”** 架构，实现对微小物理振动、生物微呼吸及微形变的毫秒级实时捕捉与直观可视化。
* **硬件平台**：
  * **开发板**：正点原子领航者 ZYNQ-7000（核心板芯片：`XC7Z020-CLG400-2`），板载 1GB 32-bit DDR3 SDRAM。
  * **图像传感器**：ATK-OV5640 摄像头模块（8-bit DVP 数字接口，配置为 720P@60fps 或 480P）。
  * **显示输出**：底板 HDMI 接口（PL Bank 35 差分管脚直接输出 TMDS 信号）。
* **功能特色**：
  * **3 大精炼核心显示模式按键/串口无缝切换**（聚焦实际应用，剔除冗余的纯黑底热力图与分屏）：
    1. 原始画质直通 (Bypass)
    2. 局部/全屏运动微动放大画面 (Motion Magnified)
    3. 局部/全屏热力图半透明叠加原画 (Heatmap Overlay - **核心推荐模式**)
  * **双调色板支持**：Jet 彩虹色谱与 Viridis 翠绿色谱硬件查表 (LUT)；
  * **振动安全阈值监测预警 (VIBRATION ALARM)**：实时监测带通微位移幅值 $disp = \max(|\Delta y|)$，当超出安全阈值（如 $3.0\text{ px}$）时触发预警，低于阈值显示正常 (NORMAL)，有效用于结构探伤与共振报警；
  * **PC 端 PyQt5 亮色上位机联动**：左屏支持鼠标拖拽框选【局部微动目标】ROI，右屏叠加呈现，底部按钮实时无缝切换。

## 二、 方案架构深度对比与优势评析

### 1. 方案对比矩阵

| 对比维度 | 方案 A：单尺度 DoG + 纯画面放大方案 | 方案 B：降采样 + 金字塔 + 幅度热力图方案（推荐） |
| :--- | :--- | :--- |
| **空间多尺度分解** | 单尺度 5×5 高斯残差 $L_0 = Y - \text{Blur}(Y)$，只提取固定频段 | 2~3 级拉普拉斯金字塔（逐级 blur + down + up 差分），解耦宏观与微观形变 |
| **分辨率与带宽** | 720P 全图直通处理，DDR3 带宽压力大，高频散粒噪点明显 | **前端降采样预处理 (720P→360P/480P)**，空间平均大幅提升 SNR，带宽降低 4 倍 |
| **可视化手段** | 仅有原画像素位移放大，微小晃动依然难于用肉眼快速察觉 | **变化幅度场 $\|\Delta\| \rightarrow$ 时间平滑 $\rightarrow$ 伪彩 LUT $\rightarrow$ 原图半透明叠加**，动静一目了然 |
| **显示模式** | 仅原画/放大/二分屏 | **3 大精炼模式**（原画直通 / 运动放大 / 热力图半透明叠加）+ 鼠标局部 ROI 框选 |
| **抗闪烁设计** | 仅依赖摄像头曝光锁定 | **曝光锁定 + 幅度场一阶时空平滑 (IIR Smoothing)**，彻底根除高频雪花闪烁 |

### 2. 为什么方案 B 实现效果显著更好？
1. **视觉冲击力与直观度**：
   对于极微弱振动（如 0.05 像素物理微震），就算放大 30 倍也仅有 1.5 像素位移，人眼在复杂背景中很难看清。**方案 B 的热力图直接给振动幅度着色（静止呈现冷蓝，剧烈微颤呈现暖红），叠加在原图上半透明显示，任何微动无所遁形**！
2. **空间降采样的信噪比 (SNR) 增益**：
   EVM 对图像噪声极其敏感。720P 下相邻像素的微弱抖动常被传感器热噪声淹没。通过 $2\times$ 降采样均值抽取，等效于空间低通滤波，信噪比大幅度提高，微动特征更容易被时域 IIR 检出。
3. **硬件资源与时序收敛友好**：
   XC7Z020 仅有 140 个 BRAM 与 220 个 DSP48E1。将视频降至 360P 后，单帧像素数锐减至 1/4，VDMA 读写突发长度更短，帧缓存 FIFO 绝不会溢出丢帧。

## 六、 传感器噪点物理成因与 ZYNQ+OV5640 软硬件协同抗噪方案

### 1. 为什么默认电脑摄像头（Cam0）噪点容易超出微动范围？
- **普通 PC 摄像头机制**：采用低成本小靶面 CMOS，室内环境下会自动拉高数字增益（AGC）与自动曝光（AEC），导致**传感器散粒噪声（Shot Noise）与读出噪声（Read Noise）高达 $3 \sim 5$ 个灰度级**；
- **EVM 放大机理**：EVM 时域滤波本质是带通差分放大。微弱物理位移产生的灰度变化往往只有 $0.2 \sim 0.8$ 灰度级（亚像素级），而噪点高达 $3 \sim 5$ 灰度级；当放大倍数 $\alpha = 30 \sim 50$ 时，**噪点被同步放大了 50 倍，直接变成暴风雪般的剧烈闪烁杂点**，将真实微动完全淹没。

### 2. OV5640 双目摄像头的感光与噪声物理机理
- **感光特性**：OV5640 是 1/4 英寸 500 万像素 CMOS，物理像素尺寸较小（$1.4\,\mu\text{m} \times 1.4\,\mu\text{m}$）。若在出厂默认配置下运行，室内低照度时内部 ISP 会大幅提高增益，同样会产生明显的噪点；
- **核心区别**：PC 摄像头大多固化在驱动底层无法手动干预，而 **OV5640 连接至 ZYNQ-7020 时，我们拥有从传感器寄存器、FPGA 像素流水线到 PC 上位机算法的 100% 完全可控权**！

### 3. ZYNQ-7020 + OV5640 的四重去噪协同体系
1. **第一重：OV5640 传感器端硬件 2D 去噪 ISP（源头滤波）**：
   - 通过 SCCB 寄存器 `0x5300` 激活片上 2D Denoise 引擎，在感光阵列输出前滤除高频暗电流噪点；
2. **第二重：锁定原生最低模拟增益（1.0x ISO 100）与适度长积分曝光**：
   - 寄存器 `0x350A/0x350B` 锁死为 `0x0010`，关闭一切数字倍增益，彻底杜绝由于高 ISO 引入的热噪声与散粒噪点；
3. **第三重：FPGA / 算法端【时域死区门限滤波（Temporal Noise Coring）】**：
   - 在带通滤波差分 $\Delta y = lowpass1 - lowpass2$ 后，实施软阈值门限：
     $$\Delta y_{\text{clean}} = \begin{cases} \text{sign}(\Delta y) \cdot (|\Delta y| - \text{Gate}), & |\Delta y| > \text{Gate} \\ 0, & |\Delta y| \le \text{Gate} \end{cases}$$
   - 低于死区门限的全部视为传感器本底白噪声，强行归零！只有超过门限的真实物理微动才会乘以 $\alpha$ 放大，彻底杜绝高倍放大时的“雪花杂波”；
4. **第四重：空间 2x 降采样与均值抽取（提升 6dB SNR）**：
   - 将 720P 降为 360P，利用相邻像素求和平均，不仅使数据吞吐量降低 4 倍，同时根据统计学原理使高斯随机噪声标准差衰减为原本的 $1/2$。
